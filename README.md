Student Data Entry Form

About

This is a basic Student Data Entry Form created using HTML. It provides an interface for entering student details such as name, email, gender, subjects, city/town, and comments.

Technologies Used

- HTML5

Features

- Student name input field
- Email input field
- Gender selection using radio buttons
- Subject selection using checkboxes
- City/town selection using a dropdown menu
- Comments section
- Submit and Clear buttons

Learning Outcomes

- Learned to create HTML forms.
- Practised different HTML input types.
- Understood the use of labels, radio buttons, checkboxes, and dropdown menus.

Project Status

Completed – Beginner HTML Project.
